# DW2 · Preset Console

面向 **TauriTavern / TT** 的独立第三方扩展。包含《织界》快捷控制、真实预设分组、常用收藏、双身份切换，以及与柏宝箱兼容的只读正则分组显示。和 DW2 · Story Archive 书架相互独立。

当前版本：**v0.3.0 · Quick Studio 测试版**。

## 安装与升级

在 TT → 扩展管理 → 从 GitHub URL 安装，粘贴：

`https://github.com/dw2devil1024-creator/dw2-preset-console`

原先已经安装的用户：在 TT **管理扩展**中更新本插件并完整刷新酒馆。v0.3.0 修改了 JS 入口版本参数，以减少 iOS WebView 复用旧模块。无需重新导入预设、正则或书架。

## 功能界面

| 页面 | 功能 |
| --- | --- |
| 快捷 | 织界专用的四组快捷设置：高频、设定、修正、引擎 |
| 分组 | 原样读取当前预设的真实分组，并支持折叠 |
| 全部 | 完整的原预设条目列表及搜索 |
| 常用 | 当前设备自行收藏的条目 |
| 模式 | 织界 / 墨团子身份二选一；小说叙事增强可叠加 |
| 正则 | 全局、预设、角色正则管理；只读读取柏宝箱自定义分组 |

### v0.3.0 快捷页

**高频**：文风库（多选、已选优先展示）、情感基调（两档）、推进节奏（三档）、成人亲密总入口。

**设定**：七种视角、玩家对白处理、内心独白、人物表现补充、正文长度三档。

**修正**：减少 AI 腔、正文纠偏、剧情推进、NPC 行动。

**引擎**：织界 / 墨团子身份二选一、沉浸世界运行总则和小说叙事增强（可双开）、初始化核心状态（只读）。

**所有选项均来自用户提供的《织界 v6.58》现有真实预设条目。** 比如字数规则只有三条，快捷页也只能切换短／中／长，不做虚假的数值滑块。文风多选不会自动关闭其他文风。

在快捷页打开卡片后可以跳转到对应原预设分组。快捷分类不会删除、覆盖或重新组织原预设数据。

### 防误操作

- 互斥项一次性保存整组的 ON/OFF 状态；不是逐条模拟点击。
- 只有全部所需条目均存在且名字唯一时，才允许对该互斥组快捷切换；避免新旧版本误关联。
- 「变量初始化｜别动」保持受保护状态，快捷页只显示状态。
- 非《织界》或未识别的预设不会被自动套用织界快捷规则；仍然可以使用原始分组、全部、收藏及正则功能。
- 所有状态都通过 TT 原生 PromptManager 保存，而不是另存一份假的状态；插件只保留收藏、折叠、布局等用户界面偏好。

## 正则分组与柏宝箱

通过 `extension_settings.baiBaiToolkit.regexListGroups.scopes` **只读**获取柏宝箱的正则子分组和脚本归属，预设来源也支持 `baibaiToolkit.regexGroups` 的可携带元数据。如果无法读取，则回退为全局／预设／局部三大类。不修改柏宝箱分组设置。

正则条目开关使用 TT 的原生保存和消息刷新接口。来源许可仍需在 TT 设置内单独开启。

## 目录

- `manifest.json`：插件入口与版本。
- `index.js`：UI、功能逻辑与原生数据接口。
- `style.css`：手机／电脑适配的磨砂玻璃风格。
- `groupMap.js`：织界原始分组名与条目 ID 的对应关系，**不包含预设正文**。
- `quickConfig.js`：快捷功能条目名称与选项，**不包含预设正文**。

## 与朋友分享

如果朋友安装的《织界》版本与 v6.58 兼容，通常只需要分享此仓库安装地址，不必重新发送预设。插件不能替代预设内容更新；如果朋友使用不同版且快捷名字不匹配，会限制那些快捷按钮，防止误操作。
