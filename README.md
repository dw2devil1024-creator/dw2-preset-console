# DW2 · Preset Console

专为 **TauriTavern（TT 酒馆）** 编写的独立悬浮控制台。这个仓库可在 TT 扩展管理器中按 GitHub 仓库地址安装。无需修改 DW2 · Story Archive（书架）。

## 当前版本 v0.2.0 · 首个测试版

- **分组**：读取当前预设自带的分组配置，或在《织界 v6.58》中使用随插件附带的 31 组、451 个条目 ID 映射；搜索、折叠、开关状态从用户当前 TT 中读取。
- **全部 / 常用**：显示当前实际预设条目，收藏只保存在本机；名字与同名出现顺序用于标记收藏。
- **模式**：《织界》身份（织界世界演绎者 / 墨团子原创小说家）互斥切换；**小说叙事增强**是独立开关，允许与世界运行规则双开。
- **保护**：「变量初始化｜别动」及 Agent System Prompt 在面板内不可误触修改。
- **正则**：直接读取 TT 的全局／角色／预设正则，用原生接口保存启停并触发聊天刷新。来源权限需要先在 TT 设置里启用。
- **界面**：轻玻璃悬浮入口、可拖动并记录位置，适配手机和桌面端。

## 安装步骤

1. 打开 TT 酒馆的扩展管理页面。
2. 选择从 GitHub URL 安装扩展。
3. 粘贴本仓库地址：

   `https://github.com/dw2devil1024-creator/dw2-preset-console`

4. 安装后按照 TT 的提示刷新。打开悬浮星号，查看「分组」「常用」「全部」「模式」「正则」。

**不要**填旧的 `dw2-story-archive` 地址；那是书架，不是预设控制台。

## 分享给其他玩家

朋友已经安装**相同版本的《织界》预设**：只需要单独安装这个插件。插件本身不会导入、替换或更新预设内容。用户在自己 TT 中修改的预设开关状态、自己的收藏与插件布局都由各自的环境管理，不共享彼此设置。

如果朋友使用不同版本或更改了预设条目 ID，插件将尽量读取当前预设原生分组；如果原生分组不可读取并且 ID 不匹配，则只显示「全部」，不会乱绑别的预设。若新增规则、修改正文，仍需用户独立更新《织界》预设。

## 数据与实现

| 文件 | 用途 |
|---|---|
| `manifest.json` | TT 扩展描述 |
| `index.js` | 悬浮 UI 与原生启停接口 |
| `style.css` | 面板样式 |
| `groupMap.js` | 仅 31 组名称、451 个条目 ID 的对应关系，不包含预设提示词正文 |

插件不上传预设文本、不删除预设、不覆盖原有正则查找或替换内容。需要网络访问的操作由 TT 原本的设置保存接口完成。
