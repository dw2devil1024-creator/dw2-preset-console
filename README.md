## 升级

在 TT → 扩展管理中找到 **DW2 · Preset Console**，点击更新，然后完整刷新 TT。也可以使用扩展设置列表中的「检查并更新」。

安装地址：

`https://github.com/dw2devil1024-creator/dw2-preset-console`

无需重新导入或替换《织界》预设；原来的书架和正则内容也不会被修改。此次更换 JS/CSS 入口版本标识（`v=0.4.12`），以降低 iOS WebView 复用旧模块缓存的概率。

### 快捷页的真实功能

1. **文风双选择器**：根据当前预设中「通用文风库」分组读取文风；原 v6.58 共 159 条，剔除 12 条分隔标题后为 147 个可选项，其中包含自定义空槽。支持搜索和两个系统原生下拉框，任一框选择／清空时仅改变该框原来绑定的文风。不会自动关闭在别处已经开启的其他文风；超过两条启用时提示核对。相同文风不可占据两个槽位。
2. **写作指导**：直接读取真实「写作指导｜字数·段落·节奏·浓度」分组的 13 条实际预设开关，包括情感基调、三档节奏、三档字数、段落长度等；不模拟数字滑块，不修改提示词。
3. **视角与落点**：直接读取「视角与落点｜沉浸镜头·小说叙事」分组的 33 条实际预设开关，默认折叠，可以展开查看与操作。

「快捷」不是另一套虚拟配置：每个开关都通过 TT 的原生 PromptManager 读取并保存。**原预设分组是唯一的数据源。** 初始化组继续保持受保护状态。

### 与旧版相比

- 不再人为凑「高频 / 设定 / 修正 / 引擎」四个快捷栏目。
- 把顶部「分组」「全部」合并成一个按真实分组整理的「全部」页。
- 原始分组的条目顺序、名称、启用状态都保持不变；快捷页可以跳转到对应原组。
- 保留「常用」「模式」「正则」独立页及其既有开关。
- 旧版 `quickConfig.js` 已移除，新的 `quickStudio.js` 专门负责快捷展示。

## 数据和兼容

- `manifest.json`：版本与模块入口
- `index.js`：主控制台、原预设分组、正则、设置入口
- `quickStudio.js`：文风双选择器与原始组快捷展示
- `groupMap.js`：织界 v6.58 的 31 组和条目 ID 映射；不包含提示词正文
- `style.css`：雾蓝／粉白玻璃界面与 iPhone／Android 样式

插件不会上传原预设文本。用户自定义的分组、正则及其内容由各自 TT 管理。柏宝箱分组数据由兼容读取器只读访问；插件不会修改其分组映射。跨版本如果名字或 ID 不匹配，会限制自动操作而不是猜测。
